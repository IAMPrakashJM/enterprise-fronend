# Enterprise frontend

A desktop-first frontend framework for reusable ERP, healthcare, school and other SaaS application interfaces. Web and desktop shells share TypeScript components, page engines, localization and preference policies. The included API supplies demo contracts and fictional data.

Application source and npm commands are under `desktop-clients/`; demo backend source is under `dummy-api/`. Use the project's Node 24 environment and follow the testing guide for isolated API/browser checks. Private workspace packages are not automatically available from a public package registry.
